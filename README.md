# خطواتي — Khatawati

تطبيق أندرويد أولي لعدّ الخطوات مع هدف يومي وتحدٍّ ومكافأة.

## إنشاء APK من GitHub باستخدام الهاتف
1. ارفع جميع ملفات هذا المشروع إلى مستودع GitHub مع الحفاظ على المجلدات.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Khatawati APK** ثم اضغط **Run workflow** (أو انتظر البناء بعد رفع الملفات).
4. بعد نجاح العملية افتح تشغيل البناء ثم انزل إلى **Artifacts**.
5. نزّل `Khatawati-debug-apk`، وفك ضغطه، ثم ثبّت `app-debug.apk` على هاتفك.

## ملاحظة
هذا إصدار أولي. يعتمد العد الفعلي على وجود مستشعر `Step Counter` في الهاتف. بعض الأجهزة لا تدعم هذا المستشعر أو قد تتطلب إعدادات أذونات/طاقة خاصة.
